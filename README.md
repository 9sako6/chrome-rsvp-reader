# chrome-rsvp-reader

選択した文章を、視線をほぼ動かさずに読める RSVP（Rapid Serial Visual Presentation）Chrome 拡張です。

日本語の技術文章を、原文を変えずに読みやすくすることを目的にしています。

## 使い方

1. `chrome://extensions` を開く
2. `デベロッパー モード` を有効にする
3. `パッケージ化されていない拡張機能を読み込む` からこのリポジトリを選ぶ
4. 任意の Web ページで読みたい文章を選択する
5. 右クリックして `RSVPで読む` を選ぶ

## 現在の表示

- RSVP の注視位置を画面中央に固定
- 改行せず、文字サイズ・行高・表示位置を単位ごとに変えない
- ページ全体の `h1`〜`h6` を左側のミニマップに表示
- 読んでいる位置に対応する見出しを強調
- Kagome v2.11.0 + UniDic v1.2.6 で形態素解析し、品詞情報を使って RSVP 向けのフレーズにまとめる
- Kagome WASM を利用できない場合は `Intl.Segmenter` と軽い日本語ルールへフォールバック
- `（...）` や `「...」` / `『...』` は、注視位置を動かさないよう文字サイズや位置を変えず、色・背景だけで区別
- 長すぎる表示単位は改行せず分割
- 原文の文字列・順序・オフセットを維持

オーバーレイでは次の操作ができます。

- `一時停止` / `再生`
- `1文戻る`
- `閉じる`

## Kagome / UniDic

形態素解析は完全にローカルで実行します。外部 API や CDN への通信はありません。

- Kagome: `v2.11.0`
- Kagome UniDic dictionary: `v1.2.6`
- Go: `1.24.0`
- WASM: `vendor/kagome/kagome-unidic.wasm`
- ビルド元: `tools/kagome-wasm/`
- ハッシュ: `vendor/kagome/SHA256SUMS`

UniDic 辞書を含むため WASM は約 50 MB あります。GitHub Actions で固定バージョンから再現ビルドし、生成物の SHA-256 も保存します。

## テスト

Node.js で追加依存なしに実行できます。

```sh
npm test
```

原文・オフセット保持、Kagome/UniDic の品詞を使ったフレーズ化、フォールバック、最大表示長、括弧・引用、文番号、`1文戻る`、見出し現在地の計算をテストしています。

## 方針

- 原文を要約・言い換え・補完しない
- 外部 API やサーバーを使わない
- RSVP の注視位置固定を、文章構造の装飾より優先する
- 形態素解析と RSVP 用フレーズ結合を分離する
- 設定はまだ保存しない
- まず選択範囲で使い、将来はページ本文の自動抽出へ拡張する
