# chrome-rsvp-reader

選択した文章を、視線をほぼ動かさずに読める RSVP（Rapid Serial Visual Presentation）Chrome 拡張です。

日本語の技術文章を、原文を変えずに読みやすくすることを目的にしています。

このプロジェクト本体はApache License 2.0で提供します。同梱する第三者ソフトウェアのライセンスは、それぞれの`vendor/`配下に保存しています。

## 使い方

1. `chrome://extensions` を開く
2. `デベロッパー モード` を有効にする
3. `パッケージ化されていない拡張機能を読み込む` からこのリポジトリを選ぶ
4. 次のどちらかで読み始める
   - 読みたい文章を選択し、右クリックして `RSVPで読む` を選ぶ
   - 拡張機能のツールバーアイコンを押し、ページから抽出した本文全体を読む

## 現在の表示

- RSVP の注視位置を画面中央に固定
- 改行せず、文字サイズ・行高・表示位置を単位ごとに変えない
- 選択範囲または記事全体の `h1`〜`h6` を、注視点の近くに浮かぶ「記事の構成」ミニマップとして表示
- 読んでいる位置に対応する見出しを強調
- `Intl.Segmenter` と軽い日本語ルールですぐに読み始める
- Obsidian Web Clipperと同じDefuddle v0.19.2で本文を抽出し、ヘッダー、ナビゲーション、サイドバー、フッター、広告などを除外
- 読み始めた後に Kagome v2.11.0 + UniDic v1.2.6 をバックグラウンドで準備し、準備済みなら次回から品詞情報を使って RSVP 向けのフレーズにまとめる
- 解析に時間がかかる場合は読み込み状態を表示
- `（...）` や `「...」` / `『...』` は、注視位置を動かさないよう文字サイズや位置を変えず、色・背景だけで区別
- 長すぎる表示単位は単語の途中を避けて、改行せず分割
- 原文の文字列・順序・オフセットを維持

オーバーレイでは次の操作ができます。

- `一時停止` / `再生`
- `1文戻る`
- `閉じる`

## Kagome / UniDic

形態素解析は完全にローカルで実行します。外部 API や CDN への通信はありません。

- Kagome: `v2.11.0`
- Kagome UniDic dictionary: `v1.2.6`
- Go: `1.24.0`
- WASM: `vendor/kagome/kagome-unidic.wasm`
- ビルド元: `tools/kagome-wasm/`
- ハッシュ: `vendor/kagome/SHA256SUMS`
- ライセンス: `vendor/kagome/LICENSES/`

UniDic 辞書を含むため WASM は約 50 MB あります。GitHub Actions で固定バージョンから再現ビルドし、生成物の SHA-256 も保存します。

## Defuddle

本文抽出にはDefuddle `v0.19.2`のブラウザ向けバンドルを同梱して使います。外部APIは利用せず、表示中のページ内だけで処理します。

- ライセンス: MIT
- 配置: `vendor/defuddle/`
- ハッシュ: `vendor/defuddle/SHA256SUMS`

## テスト

Node.js で追加依存なしに実行できます。

```sh
npm test
```

原文・オフセット保持、Kagome/UniDic の品詞を使ったフレーズ化、フォールバック、最大表示長、括弧・引用、文番号、`1文戻る`、見出し現在地の計算をテストしています。

## 方針

- 原文を要約・言い換え・補完しない
- 外部 API やサーバーを使わない
- RSVP の注視位置固定を、文章構造の装飾より優先する
- 形態素解析と RSVP 用フレーズ結合を分離する
- 設定はまだ保存しない
- まず選択範囲で使い、将来はページ本文の自動抽出へ拡張する

設計・研究メモは #1、文章構造の改善は #2、Kagome + UniDic 導入は #6 を参照してください。
