# chrome-rsvp-reader

選択した文章を、視線をほぼ動かさずに読める RSVP（Rapid Serial Visual Presentation）Chrome 拡張です。

現在は最小版です。日本語の技術文章で実際に使い、分割や速度はその後に調整します。

## 使い方

1. `chrome://extensions` を開く
2. `デベロッパー モード` を有効にする
3. `パッケージ化されていない拡張機能を読み込む` からこのリポジトリを選ぶ
4. 任意の Web ページで読みたい文章を選択する
5. 右クリックして `RSVPで読む` を選ぶ

オーバーレイでは次の操作ができます。

- `一時停止` / `再生`
- `1文戻る`
- `閉じる`

## テスト

Node.js で追加依存なしに実行できます。

```sh
npm test
```

現在は、原文を変更せずに分割できること、文番号、`1文戻る` の位置計算をテストしています。

## 方針

- 原文を要約・言い換え・補完しない
- 外部 API やサーバーを使わない
- MVP では設定を保存しない
- まず選択範囲で動かし、将来はページ本文の自動抽出へ拡張する
