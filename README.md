# chrome-rsvp-reader

選択した文章を、視線をほぼ動かさずに読める RSVP（Rapid Serial Visual Presentation）Chrome 拡張です。

日本語の技術文章を、原文を変えずに読みやすくすることを目的にしています。

## 使い方

1. `chrome://extensions` を開く
2. `デベロッパー モード` を有効にする
3. `パッケージ化されていない拡張機能を読み込む` からこのリポジトリを選ぶ
4. 任意の Web ページで読みたい文章を選択する
5. 右クリックして `RSVPで読む` を選ぶ

## 現在の表示

- ページ全体の `h1`〜`h6` を左側のミニマップに表示
- 読んでいる位置に対応する見出しを強調
- `Intl.Segmenter` と軽い日本語ルールで、一息で読めるまとまりを優先して分割
- `（...）` は補足として少し小さく・薄く表示
- `「...」` / `『...』` は可能な限り一塊で表示
- 原文の文字列と順序は変更しない

オーバーレイでは次の操作ができます。

- `一時停止` / `再生`
- `1文戻る`
- `閉じる`

## テスト

Node.js で追加依存なしに実行できます。

```sh
npm test
```

原文保持と文字位置、自然な日本語区切り、括弧・引用の構造判定、文番号、`1文戻る`、見出し現在地の計算をテストしています。

## 方針

- 原文を要約・言い換え・補完しない
- 外部 API やサーバーを使わない
- 設定はまだ保存しない
- まず選択範囲で使い、将来はページ本文の自動抽出へ拡張する

設計・研究メモは #1、文章構造の改善は #2 を参照してください。
